# Project: Ibotwe Cafeteria Ordering System

## 📌 Description
This project is a software application designed to reduce long queues in the campus cafeteria by allowing students to order food online.

Students can choose to either:
- Pick up their food at the cafeteria
- Have their food delivered to their location on campus

## 🚨 Problem Statement
Students experience long waiting times at the cafeteria, especially during peak hours, which leads to wasted time and missed classes.

## 🎯 Solution
This application allows students to:
- View available meals
- Place orders in advance
- Select pickup or delivery options
- Avoid standing in long queues
