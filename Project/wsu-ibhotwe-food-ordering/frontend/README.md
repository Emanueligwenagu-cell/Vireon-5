# Ibhotwe Frontend

This folder contains the client-side code and user interface for the WSU Ibhotwe Food Ordering Platform.

## Structure
- **`login.html`** — Multi-role authentication page (Student vs Vendor).
- **`home.html`** — Student homepage with featured meals, quick categories, and order tracking banner.
- **`browse.html`** — Full food catalog with search, category filtering, and item details.
- **`cart.html`** — Shopping cart, checkout, delivery selection, and promo code support.
- **`orders.html`** — Student order history and real-time live status tracking.
- **`vendor.html`** — Vendor order management dashboard and menu management.
- **`game.html`** — Gamified loyalty minigame for students.
- **`css/`**
  - `styles.css` — Modern responsive styles, theme variables, and layouts.
- **`js/`**
  - `app.js` — Core client-side router, session manager, and API client.
  - `components.js` — Reusable UI components (cards, badges, modals).
  - `data.js` — Client constants and initial mock data.
  - `nav.js` — Navigation handlers, mobile menu, and global logout.
  - `state.js` — Global client-side state management.
  - `utils.js` — Formatting and helper functions.
  - `pages/` — Page-specific rendering and event bindings.
